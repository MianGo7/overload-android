# Wireframes

The examination task asks for the initial app design to be presented as
wireframes. Put the exported images here, one file per screen, named after the
screen: `dashboard.png`, `goal.png`, `log-entry.png`, `history.png`,
`week-detail.png`.

Notes:

- Wireframes document the design as it was planned before implementation.
  Keep the original versions even after the app diverges from them, and
  describe the differences in the report instead of redrawing history.
- Low fidelity is fine and often better. Boxes, labels and arrows for the
  navigation between screens are enough.
- Add one diagram showing the navigation between the five activities, since
  the report has to describe how the components interact.
